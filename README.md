# SnapshotTest

## English

A small educational iOS project demonstrating snapshot testing for SwiftUI and UIKit screens with the [SnapshotTesting](https://github.com/pointfreeco/swift-snapshot-testing) library.

The tests compare the UI against reference images and are configured to run on an iPhone 14 Pro simulator with iOS 16. The project includes custom settings and extensions that simplify snapshot test configuration and execution for different UI states.

## Русский

Небольшой учебный iOS-проект с примерами snapshot-тестирования экранов на SwiftUI и UIKit с помощью библиотеки [SnapshotTesting](https://github.com/pointfreeco/swift-snapshot-testing).

Тесты сравнивают интерфейс с эталонными изображениями и настроены для запуска на симуляторе iPhone 14 Pro с iOS 16. Проект содержит собственные настройки и расширения, упрощающие конфигурацию и запуск snapshot-тестов для разных состояний интерфейса.
